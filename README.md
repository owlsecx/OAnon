## 📌 Overview

**OwlAnon** is a privacy control center that manages Tor routing and browser anonymization on Linux systems. It provides a simple GUI to start/stop anonymous browsing sessions and monitor your current network identity.

---

## 🖥️ Interface

| Element | Description |
|--------|-------------|
| **START BROWSER** | Launch browser through Tor network |
| **STOP BROWSER** | Close browser and Tor session |
| **Owl Health Check** | Verify Tor connection status |
| **IP / Country / ISP** | Live display of your current network identity |
| **Log Console** | Real-time activity and status logs |

---

## ⚙️ Requirements

- Linux (any distro)
- Tor installed and configured
- The tool is pre-built — no Python installation needed

---

## 🚀 Usage

Simply run the executable:
```bash
./OwlAnon
```

1. Click **START BROWSER** to launch an anonymous browsing session
2. Use **Owl Health Check** to confirm Tor is active
3. Click **STOP BROWSER** when done
